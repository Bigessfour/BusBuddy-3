# PowerShell legacy archive

BusBuddy `bb-*` modules and installers were **removed** (not merely deprecated) under
[issue #15](https://github.com/Bigessfour/BusBuddy-3/issues/15) (2026-08-17).

Remaining files here are one-off historical scripts (fetchability index generators, audits).
Do not restore `BusBuddy-*.psm1` / `bb-*` wrappers into the active tree.

Active helpers: `Scripts/Validate-Dependencies.ps1` and other non-module scripts under `Scripts/`.
